Reconciliation rule. Unique post URLs from Clip Log + Posted - Unmatched, de-duplicated by normalized URL (query string and trailing slash removed; Clip Log wins). A Clip Log clip's Views is one combined number, so it counts only toward its first link; later links add 0. Platform comes from the URL host. How this is counted. Every post link is read on its own and assigned by domain (tiktok.com → TikTok; instagram.com/reel|p → Instagram; youtube.com/shorts → YouTube Shorts; watch/youtu.be → YouTube long-form), de-duplicated by post ID. Views come first from the per-platform tabs (TT/IG/YTS Posts + Snapshots), then Posted - Unmatched, then a Clip Log row's Views only when that row has a single link. A Clip Log row with several links has one Views number for all of them, so its posts are counted but their views are not split and the row is flagged below rather than guessed.
